# v0.23.2

本版本基于 `dev` 分支，继续优化复杂 mihomo 配置下的内存占用，同时保持
AnyConnect/DTLS 和现有规则行为。

## 主要变化

- GeoSite 和 Domain rule-provider 使用连续内存的紧凑只读 trie。
- 避免 Domain provider 加载期间复制整份条目。
- 移除 DomainRegex 规则重复保存的正则文本。
- 使用 `SmolStr` 保存短的 rule-set 名称和 adapter。

## 验证

- ARM64 musl 静态 release 构建通过。
- `meow-trie`、`meow-rules` 全部测试和 GeoSite 压力测试通过。
- 在 OpenWrt ARM64 实机上，完整配置 RSS 约 30 MiB。
- 两个 AnyConnect 节点 HTTPS 健康检查通过。

本版本不包含节点地址、凭据或 provider 原始内容。

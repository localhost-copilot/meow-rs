# v0.22.0

本版本基于 `localhost-copilot/meow-rs` 的 `dev` 分支，新增 OpenConnect 出站，
并在所有默认 `full` 构建和发布包中启用 `openconnect-dtls` 功能。

## OpenConnect

- 支持 CSTP 控制与数据通道、VPN DNS，以及 IPv4/IPv6 TCP、UDP 转发。
- 提供 `dtls-mode: off | auto | require`。`auto` 可在 UDP 不可用时回退 CSTP，
  恢复后重新使用 DTLS；`require` 在 DTLS 失败时关闭会话。
- ARM64 musl 静态链接隔离符号的 OpenSSL，不要求路由器安装 `libssl`。
- 用户态 TCP 使用 smoltcp 0.14 / CUBIC，最低 Rust 版本升级到 1.91。

## 其他修复

- Snell v3 UDP 先等待服务器确认会话，避免首个数据包与握手同时到达时被丢弃。

## 下载与兼容性

- 所有发布包均包含 OpenConnect。Linux musl 的 DTLS 静态链接 OpenSSL；
  glibc Linux 运行 DTLS 需要系统 `libssl.so.3`，macOS 需要 Homebrew OpenSSL 3。
- OpenWrt 提供 `aarch64_generic`、`aarch64_cortex-a53`、`aarch64_cortex-a72`、
  `aarch64_cortex-a76`，其核心二进制相同；选择与设备 `opkg print-architecture`
  匹配的包。LuCI 包为 `all` 架构。
- Windows 尚无 DTLS 后端，OpenConnect 使用 CSTP；`require` 不可用。
  默认启用 Cargo feature 并不改变该平台限制。`minimal` 构建仍需显式添加
  `openconnect-dtls`。

## 验证范围

ARM64 QEMU OpenWrt 24.10.7 和物理 QWRT Cortex-A53 设备均通过三种模式、
双栈流量及 DTLS 中断/恢复检查。物理设备测试使用限速流量，未测峰值吞吐。

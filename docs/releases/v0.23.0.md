# v0.23.0

基于 `localhost-copilot/meow-rs` 的 `dev` 分支，补齐 AnyConnect 和复杂 YAML
配置的兼容行为。默认完整功能构建继续包含 OpenConnect/DTLS。

## 配置与协议

- 对齐 mihomo 的 AnyConnect 配置字段；本次不包含 F5。
- AnyConnect IPv4-only 会话遇到未协商的 IPv6 入站包时保持连接。
- 修复异步 BoringSSL BIO flush 重试状态，以及 AnyTLS UDP 首包和 SYNACK 时序。
- AnyTLS 应用配置的 fingerprint/ALPN；VLESS 默认 XUDP 并保留 Reality/Vision。
- DNS 支持 ARC、实时 `#分组` 路由、`respect-rules`、原生 UDP 上游和截断后的 TCP
  重试、独立 IPv6 开关、专用直连上游及 follow-policy。
- 实现 QUIC Initial SNI 嗅探，以及 HTTP/TLS 的端口、DNS mapping 和目标覆盖策略。
- 顶层 GeoData 模式、loader、URL 和更新配置生效，支持 GeoIP DAT 和规则/DNS 热刷新。
- `allow-lan`、`tcp-concurrent`、`unified-delay`、进程查找模式、profile 存储和
  provider 刷新后的 `empty-fallback` 生效。全局 IPv6 默认开启，DNS IPv6 默认关闭。
- 健康检查不再把未限制状态码的非 2xx HTTP 响应误判为断线；测速使用实时订阅节点，
  分组中一个节点超时不会丢弃其他节点的成功结果。

## 下载与兼容性

- 发布包使用默认 `full` 功能集合。ARM64 musl 静态链接 DTLS 所需 OpenSSL，
  OpenWrt 无需额外安装 `libssl`。
- OpenWrt 核心包提供 `aarch64_generic`、`aarch64_cortex-a53`、
  `aarch64_cortex-a72`、`aarch64_cortex-a76`，LuCI 包为 `all`。
- glibc Linux 的 DTLS 需要系统 OpenSSL 3；macOS 需要 Homebrew OpenSSL 3。
  Windows 尚无 DTLS 后端，OpenConnect 使用 CSTP，`require` 不可用。
- 最低 Rust 版本保持 1.91。

## 验证与性能边界

1341 个库测试、84 个 API 集成测试通过。完整 YAML 在 macOS 和物理 ARM64
QWRT 路由器上完成真实节点检查，两条 AnyConnect 均建立 DTLS 会话。

本地对照中 TLS 的四项 iperf 测试均快于 mihomo；DTLS 四流上传慢约 10.3%，
四流双向 TCP 回显仍慢约 33.5%。本版本不宣称全面性能对齐，后续在独立性能分支优化。
